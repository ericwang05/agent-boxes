# Box notes

- Your GitHub access is a 1 hour token for this repo only. The Mac replaces it about every 30 minutes, and you cannot refresh it yourself.
- `git` and `gh` read the current token each time, so nothing for you to configure.
- If a push or `gh` call fails with 401 or 403 about credentials, wait 2 minutes and retry once. Do not try to fix tokens or credential files.
- You can push branches and open pull requests. You cannot merge them or push to `main`; the owner reviews and merges.
